# 🎵 AI Music Generator

A browser-based music generation project developed as part of the *CodeAlpha Artificial Intelligence Internship*.

This project generates simple melodies based on the user's selected *mood* and *tempo* and plays the generated melody directly in the browser.

## ✨ Features

- 🎼 Generate unique melodies based on selected moods
- 😊 Happy mood
- 🌙 Calm mood
- ⚡ Energetic mood
- 💙 Sad mood
- 🐢 Slow tempo
- 🎧 Medium tempo
- 🚀 Fast tempo
- ▶️ Play generated melody
- ⏹️ Stop melody
- 📱 Responsive and beginner-friendly interface
- 🌐 Runs directly in the web browser
- 🚫 No external API or server required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio API

## 🧠 How It Works

The application uses JavaScript to generate predefined musical note patterns based on the selected mood.

The selected notes are converted into frequencies and played using the browser's *Web Audio API*.
